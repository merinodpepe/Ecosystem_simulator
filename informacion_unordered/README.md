# Información No Ordenada — Ecosystem Simulator

Esta carpeta contiene información extraída de internet sobre el **Parc Natural de l'Alt Pirineu**, su fauna, flora, clima, ecología, topografía y proyectos similares de simulación de ecosistemas. La información se ha recopilado mediante búsquedas web realizadas el 22 de junio de 2026.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `parque/` | Información general del parque: geografía, geología, historia, gestión |
| `animales/` | Mamíferos, aves, reptiles, anfibios y peces del parque |
| `flora/` | Vegetación, pisos bioclimáticos, especies emblemáticas |
| `clima/` | Datos climáticos, temperaturas, precipitaciones, cambio climático |
| `ecologia/` | Redes tróficas, cascadas tróficas, dinámicas ecológicas |
| `topografia/` | Relieve, geología, hidrografía, datos del grid del proyecto |
| `proyectos_similares/` | Proyectos de simulación de ecosistemas (ABM, NetLogo, RL, P-systems) |
| `referencias/` | Listado completo de fuentes consultadas |

Cada subcarpeta contiene un `README.md` con la descripción detallada y las citaciones correspondientes.
