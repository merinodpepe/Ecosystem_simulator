# Carpeta: proyectos_similares/

## Contenido
**`simulaciones_ecosistemas.md`** — Proyectos de simulación de ecosistemas relacionados, incluyendo modelos agent-based, redes tróficas, y dinámicas ecológicas en entornos de montaña.

### Nota
El proyecto Alt Pirineu Ecosystem Simulator es único por su resolución espacial (25m), integración de datos reales (DEM SRTM), y uso de GOAP (Goal-Oriented Action Planning) para comportamiento autónomo de agentes.
