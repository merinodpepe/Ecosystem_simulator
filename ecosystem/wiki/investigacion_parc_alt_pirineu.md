# Investigación del Parc Natural de l'Alt Pirineu

## 1. Información General del Parque

| Característica | Dato |
|---|---|
| **Superficie** | 79.317 ha (~80.000 ha) |
| **Creación** | 1 de agosto de 2003 (Decreto 194/2003) |
| **Ubicación** | Pallars Sobirà y norte de Alt Urgell |
| **Altitud máxima** | Pica d'Estats (3.143 m) |
| **Altitud mínima** | ~600 m |
| **Vegetación** | Pino negro, pino silvestre, abeto, haya, abedul, robles |
| **Vertebrados** | ~250 especies citadas |
| **Mariposas diurnas** | 168 especies (82% de toda Cataluña) |

Es el **parque natural más extenso de Cataluña**. Su complejidad orográfica y amplitud altitudinal generan una gran diversidad de ecosistemas: desde bosques mediterráneos de montaña hasta paisajes alpinos por encima de los 2.300 m.

## 2. Especies Emblemáticas y sus Poblaciones

| *Rupicapra pyrenaica pyrenaica* | Isard pirinenc | Población estable; varias decenas de individuos | Subespecie endémica de los Pirineos; seguimiento poblacional anual |

## 3. Mapa Topográfico del Terreno

### 3.1 Mapas existentes

| Tipo | Escala | Editor | Descripción |
|---|---|---|---|
| Mapa topográfico | 1:25.000 | ICGC (Institut Cartogràfic i Geològic de Catalunya) | 4 hojas que cubren todo el parque: NW, NE, S (Sort), SE (La Seu) |
| Mapa excursionista | 1:50.000 | Editorial Alpina | 2 mapas en carpeta; curvas maestras cada 100 m; sombreado automático 3D; cuadrícula UTM 5 km |
| Mapa geológico | 1:50.000 | ICGC | Mapa geológico comarcal del Pallars Sobirà |

### 3.2 Modelo Digital del Terreno (DEM)

El ICGC dispone de modelos digitales del terreno (MDT) con resoluciones de:
- **5 m** (LiDAR): Cobertura completa de Cataluña, descargable desde el [servidor ICGC](https://www.icgc.cat)
- **2 m** (LiDAR): Zonas seleccionadas
- **15 m**: Modelo genérico disponible en el ICGC

### 3.3 Cómo generar un mapa-matriz del terreno para el simulador

Para usar un modelo de terreno tipo raster/matriz en el simulador:

```python
import rasterio
import numpy as np

# Opción A: Descargar del ICGC (recomendado)
# 1. Ir a https://www.icgc.cat
# 2. Buscar "Model d'elevacions del terreny" o "MDT LiDAR"
# 3. Descargar las cuadrículas 1x1 km en formato ASC/GeoTIFF
# 4. Unir con gdal_merge.py o similar

# Opción B: Usar OpenTopography
# 1. Ir a https://opentopography.org
# 2. Buscar "Alt Pirineu" o coordenadas 42.65N, 1.33E
# 3. Descargar DEM (SRTM, ALOS, o EU-DEM)

# Opción C: EU-DEM (gratuito, 25m resolución)
# Descargar de https://land.copernicus.eu/imagery-in-situ/eu-dem

import rasterio
from rasterio.merge import merge
from pathlib import Path

# Ejemplo: procesar tiles descargados
tiles = list(Path("tiles_icgc").glob("*.asc"))
if tiles:
    mosaics, transform = merge([rasterio.open(t) for t in tiles])
    dem = mosaics[0]  # numpy array: (rows, cols) con altitudes en m
    
    # Normalizar a 0-1 para el simulador
    dem_norm = (dem - dem.min()) / (dem.max() - dem.min())
    
    # Guardar como CSV (matriz)
    np.savetxt("terrain_matrix.csv", dem, delimiter=",", fmt="%.1f")
    
    # O como JSON 2D para el visualizador
    import json
    terrain = {
        "metadata": {
            "source": "ICGC MDT LiDAR 5m",
            "crs": "EPSG:25831",
            "resolution_m": 5,
            "nrows": dem.shape[0],
            "ncols": dem.shape[1],
            "min_elevation_m": float(dem.min()),
            "max_elevation_m": float(dem.max())
        },
        "data": dem.tolist()
    }
    with open("terrain_matrix.json", "w") as f:
        json.dump(terrain, f, indent=1)
    print(f"Matriz {dem.shape} guardada")
```

Los datos LiDAR del ICGC son la mejor fuente por su alta resolución (5 m). El área del parque (~80.000 ha) se traduce en una matriz de aproximadamente **18.000 × 14.000 celdas a 5 m**, o **3.600 × 2.800 a 25 m** (EU-DEM).

## 4. Información Extra: Especies Críticas

### 4.1 Especies en Peligro de Extinción (Catálogo de Fauna Amenazada de Cataluña)

| Especie | Categoría | Razón |
|---|---|---|
| *Iberolacerta aurelioi* (Sargantana pallaresa) | **En Peligro** | Endemismo de área muy restringida; cambio climático altera su hábitat alpino |
| *Boloria eunomia* (Donzella de la bistorta) | **En Peligro** | Distribución muy fragmentada; dependiente de hábitats de mollera amenazados |
| *Tetrao urogallus* (Gall fer) | **Vulnerable** | Pérdida de hábitat; molestias humanas; depredación de nidos |
| *Gypaetus barbatus* (Trencalòs) | **Vulnerable** | Plan de recuperación activo; amenazas por venenos y colisiones |
| *Galemys pyrenaicus* (Almesquera / Desmàn ibèric) | **Vulnerable** | Especie relicta ibero-pirenaica; alteración de ríos de montaña |
| *Ursus arctos* (Ós bru) | **En Peligro Crítico** en Pirineos | Población mínima viable; endogamia; conflictos humanos |

### 4.2 Especies Clave para el Ecosistema

- **Gall fer (Tetrao urogallus)**: Considerado **especie paraguas** — su conservación protege todo el bosque subalpino maduro. El PNAP alberga la mejor población ibérica.
- **Sargantana pallaresa (Iberolacerta aurelioi)**: **Endemismo estricto** — casi toda su población mundial está dentro del parque. Descubierta en los 1990s. Especie indicadora de cambio climático en alta montaña.
- **Tritó pirinenc (Calotriton asper)**: **Endemismo pirenaico** que indica calidad de aguas frías y oxigenadas.
- **Ós bru (Ursus arctos)**: Especie bandera del parque; su presencia indica conectividad ecológica con el núcleo poblacional de la vertiente francesa.

### 4.3 Especies Exóticas/Problemáticas

- **Muflón (Ovis aries musimon)** y **Daina (Dama dama)**: Ungulados introducidos que pueden competir con la fauna autóctona.
- **Truita híbrida**: La truita de riu autóctona (*Salmo trutta fario*) está amenazada por hibridación con truitas de piscifactoría.
